## Session Summary - 2026-10-21

### Major Features Implemented & Merged to `main`

#### 1. VQ Perplexity Monitoring (`cce/comm/vq.py`)
- Added `VectorQuantizer` with codebook usage perplexity tracking
- `compute_codebook_perplexity()` standalone function for logging
- Entropy regularizer (`entropy_weight=0.01`) to prevent codebook collapse
- Dead code revival mechanism
- Tests: `tests/test_eval.py::test_vq_perplexity`, `test_vq_entropy_regularizer`

#### 2. Hard Budget Enforcement & Info Leakage Proof (`cce/comm/budget.py`, `cce/envs/grid_world.py`, `tests/test_grid_world.py`)
- **TokenBucket**: Strict token budget - masks `send` action logits to `-inf` when exhausted
- **No soft penalties** - hard constraint at action selection level
- **GridWorld**: Agents only see `visited_self` (own FOV) and `visited_teammates` (comm)
- **Global state** (`global_visited`, `global_coverage`) ONLY in critic's `info['global_state']`
- Rigorous test: `test_no_info_leakage_in_visited_mask` - 50-step trajectory verification
- All 10 tests pass

#### 3. Decoupled Budget Sweeps (`configs/exp/`, `cce/comm/budget.py`, `scripts/run_decoupled_sweeps.sh`)
- **`CommConstraints`**: `max_dm` (message dimension), `comm_frequency` (send every N steps), `topology`
- **`TopologyManager`**: `fully_connected`, `nearest_neighbor`, `ring`, `star`, `random`
- **`DecoupledCommBudget`**: Unified manager enforcing all constraints with hard masking
- 3 Hydra sweep configs:
  - `budget_dm_sweep.yaml`: dm ∈ {1,2,4,8,16} (fixed freq=1, topo=FC)
  - `budget_fc_sweep.yaml`: freq ∈ {0.1,0.25,0.5,1.0} (fixed dm=4, topo=FC)
  - `budget_topology_sweep.yaml`: topology sweep (fixed dm=4, freq=1)

#### 4. Frontier Baseline (`cce/baselines/frontier.py`, `scripts/evaluate.py`)
- Frontier detection: boundary between visited/unvisited cells (4-connected)
- Dispersion heuristic: penalize frontiers near other agents
- `FrontierBaseline` (decentralized) + `FrontierBaselineGlobal` (upper bound)
- Outputs standardized metrics: Coverage, T95, Overlap, Success Rate, Bandwidth
- CLI: `python scripts/evaluate.py --baseline frontier [--global-knowledge] [--record]`

#### 5. Streamlit Visualizer (`app.py`, `cce/eval/recorder.py`, `scripts/run_viz.sh`)
- `EpisodeRecorder`: Records step-by-step trajectory (grid, visited, positions, messages, metrics)
- Dashboard: layered Plotly grid (obstacles, per-agent visited, agent stars, comm lines)
- Coverage chart over time with 95% target line
- Bandwidth usage chart
- Message table + full message log
- Launch: `bash scripts/run_viz.sh` → http://localhost:8501
