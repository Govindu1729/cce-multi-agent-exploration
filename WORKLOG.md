# WORKLOG: Communication-Constrained Multi-Agent Exploration

## Project Overview
This repository contains the implementation for the "Communication-Constrained Multi-Agent Exploration" project. The goal is to study cooperative exploration by multiple agents in unknown grid environments under limited communication resources, formulated as a Dec-POMDP-Comm.

## Architecture & Implementation
- **Environment (`cce/envs/`)**: Vectorised grid-world with procedural map generation, local visited masks (no info leakage), and Manhattan-distance communication.
- **MAPPO (`cce/algo/`)**: Shared actor + centralised CNN critic, GAE, value normalisation, MLP/GRU backbones.
- **Communication (`cce/comm/`)**: VQ bottleneck with EMA codebook + dead-code revival + straight-through estimator, Lagrangian budget controller with PID.
- **Evaluation (`cce/eval/`)**: Coverage, T95, overlap, Pareto frontier with Kneedle, message entropy, mutual information analysis.

### 2. Fix: PyTorch 2.6 `weights_only` Unpickling Error
- **File**: `evaluate.py`
- **Issue**: PyTorch 2.6 changed the default of `weights_only` in `torch.load()` to `True`. Our checkpoints contain numpy scalars in the `stats` dictionary, which are blocked by the restricted `WeightsUnpickler`.
- **Fix**: Explicitly set `weights_only=False` in `torch.load()` since the checkpoints are generated by our own trusted training script.
- **Commit**: `fix: resolve PyTorch 2.6 weights_only unpickling error in evaluate.py`

### 3. Feature: Curriculum Learning "Bootcamp" for Silence Collapse
- **Files**: `cce/algo/mappo.py`, `cce/envs/grid_world.py`, `cce/comm/budget.py`
- **Issue**: MAPPO with a communication cost penalty naturally learns "silence collapse" (never communicating) because the cost outweighs the delayed coverage reward.
- **Fix**: Implemented a 120-update warmup phase ("Bootcamp") where communication is free (`comm_cost_scale=0.0`) and incentivized (`send_bonus=0.5`). The PID budget controller's lambda is pinned to 0.0 during warmup. After warmup, constraints are gradually applied.
- **Commit**: `feat: add curriculum learning bootcamp logic to mappo.py and env hooks`

### 4. Integration: Kaggle GitHub Workflow
- **Issue**: Manually zipping and uploading the codebase to Kaggle for every change is inefficient and breaks version control.
- **Fix**: Created `scripts/kaggle_clone.py` to allow Kaggle notebooks to directly clone the private GitHub repository using a deploy key or personal access token, ensuring Kaggle always runs the latest committed code.
- **Commit**: `feat: add Kaggle GitHub-integration workflow`
